# `plan-execution` composition

- **Target and responsibility:** Dependency-aware implementation with leaf contracts, minimum scope, and verified evidence.
- **Sources:** `agent-ctrl.old/settings/claude/agents/omo-atlas.md`, task delegation and verification; `agent-ctrl.old/settings/claude/agents/omo-sisyphus-junior.md`, leaf scope; `agent-ctrl.old/skills/parallel-execution-optimizer/SKILL.md`, dependency lanes; `agent-ctrl.old/rules/minimal-engineering.md.disabled`, decision ladder; current [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) `packages/shared-skills/skills/ulw-execute/SKILL.md`, done-claim and evidence discipline.
- **Behavior taken:** opt-in local commits chosen at plan approval (`commits: none | per-task | per-phase`, default `none`), adapted from the ulw-plan Commit strategy and per-todo Commit line: executor-only, serialized, write-set staging, hooks honored, hashes in the ledger; a resumable run state under `.agents/state/<slug>/` (state, append-only notepad, JSONL ledger, captured evidence) adapted from Boulder, Atlas notepads, and the ulw-execute ledger, with the orchestrator as its only writer (`references/run-state.md`); approved-plan start, in-progress/blocked resume, completed-plan rejection, lifecycle transitions, declared write sets, exclusive shared surfaces, safe parallelism, self-contained tasks, local conventions, owning-layer minimal change, bounded recovery, parent verification, and final gates.
- **Merge:** Legacy execution, minimal engineering, and current OMO evidence concepts become one portable execution contract with references.
- **Provider adaptation:** No provider categories, worktree state, or invocation syntax; agent delegation policy remains in agent prompts.
- **Exclusions:** Maximum parallelism, forced worktrees/TDD/manual artifacts, automatic PR/merge, and blanket language policies were omitted.
- **Attribution:** Original rewrite inspired by legacy agent-ctrl and Oh My OpenAgent execution materials.
