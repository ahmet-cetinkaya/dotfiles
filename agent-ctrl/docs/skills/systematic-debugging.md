# `systematic-debugging` composition

- **Target and responsibility:** Observed-state debugging from reproduction through minimum root fix and regression evidence.
- **Sources:** `agent-ctrl.old/agents/root-cause-analyst.md`, evidence and hypothesis testing; `agent-ctrl.old/commands/ac/fix.md`, causal chain, reproduction, minimal fix, and verification; current `agent-ctrl/.local/oh-my-openagent/packages/shared-skills/skills/debugging/SKILL.md`, runtime truth, hypothesis phases, failed-round escalation, and red/green proof.
- **Behavior taken:** First invalid state, competing predictions, one discriminating test, explicit invalidation, two-attempt advisor escalation, three-approach blocker, and cleanup.
- **Merge:** Root-cause persona and fix workflow become a reusable skill with a compact hypothesis ledger.
- **Provider adaptation:** Runtime-specific references and provider agent-call examples are replaced by project tools and the portable advisor role.
- **Exclusions:** Mandatory specialist debugger suites, three-advisor panels, automatic commit, and unsupported runtime dogma were omitted.
- **Attribution:** Original synthesis informed by legacy agent-ctrl and Oh My OpenAgent debugging material.
