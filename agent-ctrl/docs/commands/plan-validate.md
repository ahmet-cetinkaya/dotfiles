# `/ac:plan-validate` composition

- **Target and responsibility:** Independent read-only adversarial validation of a plan's decisions, feasibility, dependency graph, safety, rollback, and evidence.
- **Sources:** `agent-ctrl.old/commands/ac/plan-validate.md`, assumption/loophole loop; legacy council/devil's-advocate behavior; current `risk-review`, `advisor`, `work-planning`, and `secure-engineering` contracts.
- **Behavior taken:** Assumption busting, repository/external fact checking, dependency/write-set analysis, risk and rollback review, verification challenge, concrete amendments, and residual-risk reporting.
- **Merge:** The old red-team hub becomes a read-only structured verdict using explorer/researcher/advisor instead of retired personas and councils.
- **Provider adaptation:** Plain agent/skill routing replaces persona metadata and provider syntax.
- **Exclusions:** Pseudo-precise 95% confidence threshold, automatic plan rewrites/status changes, fixed three-round ceremony, and plan-estimate dependency.
- **Attribution:** Original synthesis from the local legacy catalog and current core contracts.
